# Checklist de la porte de lancement unique

> Version 1.0 · 26 octobre 2026 · **Rien n'ouvre au public tant qu'une seule case reste vide.** Le jour où toutes sont cochées, les trois modèles, les quatre univers et les deux villes ouvrent ensemble. Chaque case renvoie à une preuve archivée.

## 1. Juridique et conformité

- [ ] Avis juridique écrit sur la qualification des modèles A, B, C (REG-AGR-001)
- [ ] Position de la COBAC ou confirmation équivalente sur le risque de collecte de dépôts
- [ ] Agrément ou adossement validé pour les services de paiement (REG-AGR-004)
- [ ] CGU, conditions par modèle, barèmes de sortie, charte de recouvrement publiés (REG-CON-002)
- [ ] Contrats types tripartites du modèle C validés (REG-PLN-001)
- [ ] Formalités loi 2024/017 accomplies ; DPO désigné ; DPIA réalisées (REG-DPD-*)
- [ ] Responsable conformité LBC/FT désigné ; procédures écrites (REG-LBC-006)
- [ ] ADR-0004 (hébergement) tranché et mis en œuvre

## 2. Partenaires financiers et paiements

- [ ] Convention signée avec l'établissement de cantonnement (REG-AGR-002)
- [ ] Convention signée avec le financeur du modèle B (REG-AGR-003)
- [ ] Contrat agrégateur signé ; MTN MoMo et Orange Money testés de bout en bout ; USSD opérationnel sur les deux réseaux
- [ ] Canal agréé pour les contributions de l'étranger
- [ ] Rapprochement à trois voies exécuté avec succès 7 jours consécutifs en préproduction (INT-REC-001)
- [ ] Témoins (établissement, financeur) reçoivent et vérifient les têtes signées (INT-ANC-004)

## 3. Réseau de partenaires

- [ ] Marchands signés et formés dans les 4 univers, à Yaoundé **et** à Douala
- [ ] Bailleurs ou agences, écoles, vendeurs de matériaux vérifiés (modèle C) dans les 2 villes
- [ ] Concessionnaires motos / fournisseurs de matériel (mobilité) dans les 2 villes
- [ ] Points de remise et de dépôt espèces opérationnels

## 4. Produit et sécurité

- [ ] Tous les lots 00 à 25 fusionnés ; matrice de traçabilité : toutes les exigences au statut V
- [ ] Vérificateur indépendant sans divergence sur 7 jours (INT-VER-002)
- [ ] Liste ASVS 5.0 (L3/L2) et MASVS-L2+R renseignée avec preuves
- [ ] Test d'intrusion indépendant : 0 faille critique ou haute ouverte (SEC-SDLC-006)
- [ ] Tests de charge à 3× les cibles réussis (NF-PERF-005)
- [ ] Restauration complète testée et vérifiée (OPS-BAK-003)
- [ ] Exercice de crise réalisé (SEC-INC-004)
- [ ] Interrupteur d'arrêt des flux sortants testé (SEC-INC-003)

## 5. Opérations

- [ ] Support dimensionné et formé ; procédure de réclamation publiée
- [ ] Astreinte 24/7 en place sur les alertes critiques
- [ ] Agents terrain recrutés dans chaque ville
- [ ] Test fermé avec 50 clients réels terminé ; indicateurs de l'étape 23 conformes

## 6. Décision

- [ ] Revue finale du registre des risques
- [ ] Décision d'ouverture signée par le fondateur, datée, archivée
