Couleurs

Le noir porte la confiance, les couleurs portent les projets

Les actions (boutons, navigation) restent toujours en noir, ou en blanc sur fond sombre. Les couleurs vives ne servent qu'aux univers : jamais pour un bouton, jamais pour une erreur. Ni jaune ni orange, pour ne pas évoquer MTN ou Orange Money.

À régler avant de déposer le logo : le nom

« MoloPay » est très proche de MoloMoloPay, application ivoirienne de paiement différé citée dans vos sources. Le Cameroun et la Côte d'Ivoire relèvent tous deux de l'OAPI. Faites vérifier la disponibilité à l'OAPI par un conseil en propriété industrielle. L'identité ci-dessus fonctionne avec un autre nom : seul le mot à côté de l'anneau changerait.

Et ensuite

Vos retours, puis le design system

Dites-moi ce qui vous plaît et ce qui ne vous plaît pas : les couleurs d'univers, le noir, la typographie, les écrans. Une fois validée, je construis le design system complet (jetons clair et sombre, tous les composants, règles) et je l'applique au code : packages/ui pour le web et le thème Flutter pour le mobile.
